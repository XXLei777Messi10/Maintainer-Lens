# Contributing

Thanks for helping improve Maintainer Lens.

## Good first contributions

- Add realistic GitHub event fixtures.
- Improve label and priority heuristics.
- Add tests for maintainer workflows.
- Improve documentation for Action setup.

## Development

Run the test suite:

```bash
npm test
```

Run the demo fixture:

```bash
npm run demo
```

## Pull request expectations

- Keep changes focused.
- Add or update tests for behavior changes.
- Explain how the change helps maintainers.
- Avoid sending secrets, tokens, or private repository data in fixtures.
